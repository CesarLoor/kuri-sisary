# Kuri Sisary

Sitio web estático de Kuri Sisary, licor espumoso artesanal de mandarina y azafrán.

- Contenido del sitio: carpeta `site/` (`index.html` y el logo).
- Despliegue automático: `.github/workflows/deploy.yml` publica `site/` en GitHub Pages con cada push a `main`.
- Pendiente: completar los datos entre corchetes en `site/index.html` (precios, WhatsApp, Instagram, correo, zonas de entrega, ficha técnica y registro sanitario).
